# NEXOVAS ERP v3.0

This repository contains the complete NEXOVAS ERP v3.0 documentation suite generated from the source product, technical, app-flow, and design documentation provided in the project brief.

## Purpose

The documents in this repository are intended to act as a one-stop engineering and product baseline for:

- product decisions
- system design
- backend and data architecture
- API contracts
- security and compliance requirements
- workflow design
- implementation planning
- executive review and board readiness

## Repository Layout

- `brain/` — core product and technical requirements
- `data/` — schema, relationships, and data movement
- `api/` — API endpoints, contracts, and error handling
- `rules/` — business and permissions logic
- `security/` — security model and controls
- `workflows/` — operational and user journeys
- `decisions/` — architecture decision records

## Source Integrity

This repository preserves the disclosed requirements and system architecture from the supplied project materials, including the board-ready PRD, TRD, app flow, and design specs.
